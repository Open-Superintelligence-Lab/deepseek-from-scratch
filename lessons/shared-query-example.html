ONE SHARED MEMORY · TWO READS

The same KV memory can give two different outputs

Sharing keys and values saves storage, but it raises a useful question: if two layers read the same two memory entries, must they get the same answer? No. Each read can use a different query, which changes the attention weights before the values are combined.

Query A puts more weight on the first fixed value. Switch to Query B: the keys and values stay exactly the same, but the weights and output reverse. Different queries can produce different outputs; they are not guaranteed to do so for every possible pair of queries and memory entries.
